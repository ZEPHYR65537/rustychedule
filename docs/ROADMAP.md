# 后续迭代

## 当前版本边界

- 配额、价格、进度、模型倍率都由用户录入。
- 固定周期使用秒数，非日历月；不预测 Tibo。
- 规划只考虑当前额度和一次连续工作时段；按贪心策略决定可完整安排的任务。
- 任务只保存当前编辑结果；用量和预算保留历史，尚未完整记录每次任务字段修改。
- 不调用模型、不替用户执行真实重置、不提供图形界面。

## v0.2：更精细的人工规划

1. 分阶段任务和交接包，分别设置输入/输出需求、进度、质量要求及交接固定开销。
2. 可配置优先分权重与冻结指定预算，重规划时支持保护当前执行片段。
3. 规划结果持久化版本、前后差异、任务/模型降级路径图。
4. 卡库存纠错流水、任务编辑审计、额度规则编辑和迁移向导。
5. shell 补全、CSV 报表、无 Unicode 输出选项。

## v0.3：时间与不确定性

1. 纳入已知未来自然重置、多天日程与实际可工作时间段。
2. 为倍率/估计设置置信区间和保守预算策略，不能将 token 当作成果。
3. 若有足够历史样本，提供 Tibo 频率统计；默认可执行计划仍不依赖随机刷新。
4. 可选整数规划求解器，明确目标顺序、不可比模型的破平局策略与最优性边界。

## 自动采集阶段

1. 只读采集供应商官方暴露的用量，保留每模型账本。
2. 来源标注、幂等去重、手动校准优先级与冲突处理。
3. 经用户授权的重置执行适配器，真实执行与本地记账采用可恢复事务。
4. 全部变更维持 `DECISIONS.md` 中的用户约束，并提供旧版数据迁移和回归算例。

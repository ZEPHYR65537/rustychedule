## 当前边界

- 不记录价格、金额或费用；只管理用量。
- 不调用模型、不购买 tokens、不执行厂商账户重置；外部已经发生的用量/刷新由用户登记。
- 规划使用当前额度和一次连续时间段，贪心不保证全局最优。
- 周容量和模型倍率靠人工估计，无自动学习或预测。
- Git 账号只用于生成中心仓库地址，用户预先建私有仓库并配置 Git 认证。
- Agent 文档与结构支持 Git 分支合并并校验；规划账本仍有单写端冲突保护，不自动合并消费记录。
- 新版代码一律维护引用，未推送代码不跟随 hub；本地-only 索引不能恢复正文。旧 snapshot 仅保留兼容恢复。
- 任务/配置保存现值，用量/校准/刷新保留流水；还不是全事件溯源系统。

## 下一版本：人工管理体验

1. 分阶段任务、交接包、独立输入/输出估计及质量验收点。
2. 可配置优先级权重、冻结预算、计划版本及前后差异。
3. 卡库存纠错流水、估计配置历史、规划账本对账向导。
4. shell 补全、交互式初始化、CSV、ASCII 视图和窄终端模式。
5. 同步状态差异与冲突选择向导；可选 GitHub CLI 私有仓库创建，不保存密码。

## 时间、多设备与自动采集

1. 纳入已知未来自然重置、多天日程、工作空档；随机 Tibo 不提供保证容量。
2. 为规划账本引入全局唯一 ID、事件幂等键与对账规则；agent 元信息已使用稳定随机身份与 Git 合并。
3. 厂商只读用量采集写入同一事件层，保留人工校准优先级与每模型/来源维度。
4. 可选整数规划求解器，明确任务优先、模型偏好、估计风险的目标顺序。
5. 如果未来提供真实重置适配器，必须有用户显式授权、可恢复执行记录；不能把当前的本地登记命令悄悄改成远程重置。

任何迭代都必须遵守 DECISIONS.md，改变数学语义同步更新 MATHEMATICS.md，数据不兼容时增加迁移与回归测试。

## Agent 工作空间后续增强

- 平台官方接口/导出格式适配；现阶段是显式文件、来源链接和摘要，没有自动读取隐藏云端记忆。
- 更友好的冲突选择与内容语义比较，不默认用模型拼接指令。
- 普通文件 ACL、执行位和扩展属性的可携带策略；目前只同步文件正文和目录结构。
- 源目录重命名的 Git/哈希辅助识别，以及多个本机工作副本的独立采集基准；目前一节点一本机活动来源。
- 原本只维护索引的仓库显式文档快照入口；目前可把该仓库下的具体文档目录另行 import。
- 大资料的 LFS/外部对象支持；当前采用明确大小/深度限制，不自动上传任意大文件。
